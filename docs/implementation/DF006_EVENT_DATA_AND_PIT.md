# DF-006 공시 자료와 시점 계보

대상은 DF005의 사전 선정 50개 코드이며, 현재 생존 표본이다. 신규 KIS 조회는 0회다.
기존 49개 비어 있지 않은 종목 가격 캐시(2022-09-01~2025-10-16)를 재사용했다.
상장폐지·거래정지 전체 이력이나 당시 종목군을 새로 확보한 것은 아니다.

OpenDART `list.json` B001, 정정 포함 `last_reprt_at=N`, 월별 100행 페이지로
2022-10-17~2025-10-08을 조회했다. 37개 달력 구간의 210페이지와 후보 원문
`document.xml` 2개, 총 212회 요청이다. 별도 인증 발급 호출·KIS·계좌·주문·취소는 0회다.
대상 코드에 속하는 공시 302건, 공시가 있는 회사는 36개다. 이는 50개 회사의
모든 종류 공시를 포괄한다는 뜻이 아니다. 승인 범위는 B001뿐이다.

자기주식 관련 39건 중 신탁 관련 29건과 처분 관련 8건은 D1 신호로 사용하지 않았다.
동결한 직접 취득 결정 원공시는 2건이며 정정으로 사건 수를 늘리지 않았다.
두 사건 모두 가격이 있어 사건 기준 가격 누락은 0건이다. 가격이 없는 494120은
종목군 분모에 남아 있으며, 해당 코드의 적격 사건은 발견되지 않았다.

원문 XML의 COMPANY-NAME에 있는 정확한 AREGCIK 법인 식별자와 API 법인 코드,
원문 회사명에 포함되는 API 회사명, 접수번호가 같은 ZIP 원문을 대조했다.
최초 파서는 회사명의 완전 일치를 요구해 법인명 표기 차이를 불일치 처리했다.
가격 수익을 보기 전에 원문 식별 구조로 이를 보완했으며 최초 시도는 private
`data/data-first-private-df006-attempts/identity-parser-v1/`에 보존했다.
현재 종목 마스터로 과거 코드를 역산하지 않았다. 다만 API의 과거 접수 메타데이터와
원문 법인 식별을 대조한 것이며, 전체 과거 코드 변경 이력/PIT 마스터의 인증은 아니다.

| 코드 | 접수일 | 첫 판단 세션 | 공개시각 근거 |
|---|---|---|---|
| 023150 | 2024-08-27 | 2024-08-28 08:00 KST | 접수 날짜만 확인 |
| 263020 | 2024-10-28 | 2024-10-29 08:00 KST | 접수 날짜만 확인 |

실제 수집 시각은 2026년의 관측값으로 따로 보존했다. 과거 08:00/09:00:01은
실제 공개·체결 시각이 아니라 접수 날짜가 완전히 끝난 후의 탐색 가정이다.
지수 관측 세션과 DF005의 알려진 특별 개장일 제외를 사용했으나 완전한 PIT
거래·정지 캘린더는 아니다. 후속 정정은 그 정정의 가용 경계 이후에만 처리한다.
미확인 정정 연결을 제목만으로 만들어 최초 신호를 소급 변경하지 않는다.

원·수정 가격을 사건 전체 구간 및 21세션 준비 구간에서 대조했다. 변화하는 조정계수,
빠진 세션, 거래량/거래대금 0이면 사건 전체를 격리한다. 두 구간은 이 검사를 통과했지만
기업행위 전체 이력을 확보했다는 뜻은 아니다. 실행에는 원가격만 쓴다.
원문·가격·상세 거래는 Git 제외 private store, 공개 결과에는 집계와 해시만 기록한다.

## 수집 간격 미준수

원로그상 211개 연속 요청 간격 중 70개가 승인된 최소 3.05초보다 짧았다.
최소 3.035479초, 최대 부족분 0.014521초이며 3초 미만은 없었다.
이는 **엄격한 승인 간격 준수 실패**다. 임계값을 낮추거나 합격 처리하지 않는다.
Windows `monotonic()` 해상도는 0.015625초, `perf_counter()`는 0.0000001초였다.
수정본은 고해상도 시계로 3.10초 대기 후 재검사한다. 조기 깨어남·거친 시계 시험을
통과했지만 수정본으로 새 인증 수집은 하지 않았다. 실제 수집기의 실행 소스 사본과
원로그, SHA-256을 보존했다. 실행 후 알려진 변경을 제거해 복원한 소스 사본임도 명시한다.
