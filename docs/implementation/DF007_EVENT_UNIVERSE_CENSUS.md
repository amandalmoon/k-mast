D1 후보 법인은 301개, 기존 50코드 밖 후보는 618건·299개 법인이다. 모델 진입일은
347개, 사전 21개 지수 종가로 정의한 하락 국면 후보는 91건이다. 시장 표기/지수가
불명확한 후보는 88건이다. 모델 진입일과 시장 국면은 날짜 단위 조사 대용값이며,
당시 상장상태·실제 공개시각·거래 가능성을 검증한 값이 아니다.

D1에서 주식코드가 없거나 불명확한 42건을 삭제하지 않았다. API 메타데이터에서 같은
법인에 여러 유효 코드가 나타나거나 같은 코드가 여러 법인에 나타난 경우는 0건이지만,
이는 과거 코드 변경·상장폐지가 없었다는 증거가 아니다. 전체 상장·폐지·거래정지와
기업행위 이력은 UNKNOWN이다. 현재 종목 마스터로 과거 공백을 채우지 않았다.

같은 회사/같은 날짜의 원공시 충돌 후보군이 D1에서 2개 존재한다. 원문과 정정 연결을
확인하기 전 620개 접수번호를 620개 독립 사건으로 확정하지 않는다. 이미 문서와
가격을 확인한 가족은 DF006의 2건이고, 나머지 618건의 원공시 가족 연결은 미확인이다.
법인별 원공시 제목 점유율 최대는 D1 3.39%, D2 1.49%다. 성과 집중도는 계산하지 않았다.

## D2는 별도 공급 조사

D2의 후보 법인은 467개, 모델 진입일 450개, 하락 국면 후보 211건이다. 신탁계약의
체결 결정과 연장·해지·실제 취득은 섞지 않았다. DF006의 신탁 관련 29건 전체가 새
체결 결정은 아니며, 기존 50코드의 D2 원공시는 6건이다.

D2의 가설은 계약 결정의 새 정보가 다음 거래 가능시점 이후에도 남는가다. 가격 성과,
진입·보유기간·청산 규칙과 비용 후 손익은 계산하지 않았다. D1의 두 수익으로 D2 규칙을
선정하지 않는다. 별도 프로토콜 동결 전에는 백테스트하지 않는다.
초기 문서 검증만 해도 현재 D2 제목군 943개 원문, 재시도 1회 포함 최대 1,886조회가
필요할 수 있다. 연장·해지 연결은 추가 의존성이므로 이 숫자는 완결 비용의 상한이 아니다.

**EVENT_DATA_DEPENDENCY_PENDING**. 사건 공급은 기존 두 건보다 넓다. 추가 연도를
조회하기보다 현재 원자료의 원문·과거 식별·가격 계보를 먼저 확인할 가치가 있다.
새로운 거래 적격 사건을 확보했다고 선언하거나 확인적 OOS로 승격하지 않는다.
