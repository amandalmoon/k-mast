코드 `rights.py`는 각 목적의 ALLOWED/RESTRICTED/PROHIBITED/UNVERIFIED, 직접 본문/해석,
문서 참조·제약을 따로 표현한다. 메모리 분석 권한이 저장 권한을 요구하지 않도록 분리했다.
출처 없는 허용, 제목만 확보된 자료, 다른 host, 해석에 근거한 무조건 허용은 승인하지 않는다.
개인·로컬 범위 밖의 사용도 거부한다. 결과의 ALLOWED_SCOPED_NOT_G1_APPROVAL은 목적 판정이다.
기존 LicenseScope.research_allowed와 G1의 보수적 묶음 조건은 변경하지 않았다.
현재 로컬 파이프라인은 저장·백테스트까지 필요하므로 전체 연구 G1을 PASS시키지 않는다.

|---|---|---|---|
| SESSION_UNVERIFIED | 해당 TR의 OHLC 집계 세션·시장·효력기간; KIS/거래소/공급자 계약 | Observation session/bar_start/end와 원천 설명 version; adapter 승인 전 원본 별도 보존 | 원주가 60행 모두 flag 유지. 정규장 시간만 알아서는 집계 범위를 증명 못함 |
| ADJUSTMENT_HISTORY_UNVERIFIED | 분할/병합·배당·권리·계수·발표/효력/지급일; KRX/계약 벤더 | corporate action lineage, adjustment_asof; RAW 체결+권리 장부와 수정 가격 중복 금지 | 조정 60행 flag 유지. 원·수정 값이 같아도 사건 없음으로 인증 불가 |
| INDEX_HISTORICAL_RELEASE_UNVERIFIED | 과거 index 확정·정정본과 공표 정책; KIS/거래소/벤더 | evidence-backed availability_method, available_at, version | index 60행 flag 유지. 오늘 업데이트 안내를 과거 전체에 소급하지 않음 |
| 과거 available_at | 시점별 release 근거와 지연 정책 | OBSERVED와 DOCUMENTED/CONSERVATIVE_BOUND 분리, 새로운 파생 버전·출처 참조 | 획득시각 보존; 가짜 과거 시각 없음 |
| PIT universe | 당시 master, 코드 재사용·상장/상폐·정지·업종 이력 | SecurityStatus valid_from/to, available_at, universe_asof | 미확보. 현재 상장 목록으로 과거 생성 금지 |
| calendar | 공식 거래일·특별장·휴장·세션·정지 구분 | 명시 grid와 day_status; 기대 거래일만 결측 분모 | 미확보, 결측률 null. 관측된 날짜 집합을 공식 달력으로 바꾸지 않음 |

실제 180행/독립 주식 날짜 60일, 중복·상충 키 0, 원주가 입력 거부 60행이 유지된다.
원본·정규화 hash 재검증 성공은 데이터의 완전성·PIT까지 증명하지 않는다.
추가 시장자료 0행, 실제 인증 0회, 시세·계좌·주문·취소 0회. 어떠한 품질 flag도 제거하지 않았다.

## 5. 공식 문의 초안 — 사용자가 발송

제목: 개인 OpenAPI의 2026-10-06 시세 이용 정책 적용 및 연구·보관 조건 문의

개인 본인 자산운용을 위한 프로그램을 개발 중입니다. 공개 FAQ의 개인 PC 저장·가공·분석 범위를
확인했습니다. 다음 항목에 적용되는 약관 버전·조항과 허용 조건을 서면으로 알려주십시오.

1. 본인 투자 전략의 비공개 과거 백테스트가 허용되는 분석에 포함되는지, 범위·제한은 무엇인지.
2. 원본과 정규화 자료를 로컬 DB에 수년 보관할 수 있는지, 최대기간과 탈퇴/서비스 종료 후 조건은 무엇인지.
3. 가격을 복원할 수 없는 집계 성과·검사 메타데이터·소스 해시 공개는 콘텐츠 업로드 제한의 예외인지.
4. 당시 종목군·상폐·정지·기업행위·수정계수·과거 확정 시각·정정 이력을 어느 상품에서 제공하는지.
5. 해당 자료의 개인 이용 계약, 다운로드/보관 한도, 비용 및 적용 수수료 근거는 무엇인지.

실제 문의 발송·유료 계약·새 인증은 수행하지 않았다. API 키나 계좌번호를 문의 초안에 넣지 않았다.
