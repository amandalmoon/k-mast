확인일 2026-10-16. 실제 시장자료 **0행**. KIS/DART 인증·시장 조회 **0회**.
사용자는 KIS 키 보유 및 시세 전용 인증/읽기를 허용했으나 이번 실행의 로컬 키 설정은
하지 않기로 답했다. 비밀파일 탐색·키 수집·계좌 조회는 하지 않았다. API 접근 불가를
추정한 것이 아니라, 이 실행에 사용할 자격정보가 제공되지 않았다는 구체적 blocker다.

## 다음 데이터 확보 단계

1. 사용자가 준비할 때 `scripts/setup_kis_readonly.py`를 로컬 대화형 터미널에서 실행한다.
   숨김 입력으로 키를 저장소 밖 사용자 전용 ACL 폴더에 저장하며 인증은 실행하지 않는다.
   환경 LIVE/PAPER를 키 발급 환경과 일치시킨다. LIVE 시세 서버는 주문 승인이 아니다.
2. 기존 `kmast.data.cli read`에 명시 credentials-file과 read-only flag를 넘겨 심볼 한 개,
   짧은 기간·최대 요청수로 인증/시세 스키마부터 검증한다. [KM-001 실행법](KM001_USAGE.md).
   현재 permit은 최대 2심볼/366일/50요청이며 임의로 완화하지 않는다. 장기 수집 전에
   사용자와 유량·대상·기간·저장 권한을 명시하고 검증된 페이지 경계로 수집한다.
3. A를 우선한다. 현재 종목목록 대신 당시 universe/상폐 포함 마스터를 확보하고 KRX
   정규장 RAW 일봉·지수의 공통 세션 grid와 기업행위를 연결한다. 새로 내려받은 시각을
   과거 공개시각으로 되돌리지 않는다. historical release evidence가 없으면 PIT HOLD다.
4. 일별 원문/정규화/기간·유니버스/결측 분모/정지/권리/허용 사용·가용시각·비용을 manifest로
   동결하고 A 범위의 DATA_READY를 별도 심사한다. 다운로드 성공 exit code는 준비 승인이 아니다.
5. 실제 비용·지연·체결 가능 시각과 cash/시장/25% hold/PBASE_FIXED의 같은 자본·위험·비용
   대조를 등록한 뒤 연구 구간을 실행한다. B/C는 호가/체결 이력, D는 공개 경계/기대 기준을
   추가 확보한 범위에서만 확장한다. 잠금 OOS는 새 사전 승인 연구로 분리한다.

이번에 KIS 키 설정을 하지 않는다는 답변 이후 추가 설정을 요구하지 않았으며,
실제 인증을 자동 재시도하거나 예약하지 않았다. KM-004·원격 push/PR·배포·실제 거래는 시작하지 않는다.
