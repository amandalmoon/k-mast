# DF-006 이벤트 경제성 평가

판정은 **D_EVENT_INSUFFICIENT_EVIDENCE**다. 두 사건에서 비용 후 양수가 계산됐지만
회수 가능한 반복 순기대수익을 확인하지 못했다. 실제 체결 손익은 NULL이다.

각 사건은 자본 1천만원의 별도 reference 계정이다. 아래 금액을 하나의 계좌 수익으로
더하지 않는다. 가격 구간은 이미 관측된 탐색 표본이며 확인적 OOS는 미실행이다.

| 종목 | BASE 순손익 | STRESS 순손익 | BASE D1−A0 | BASE D1−추세 | BASE D1−placebo |
|---|---:|---:|---:|---:|---:|
| 023150 | +1,977.70원 | +1,752.25원 | +2,577.70원 | +2,577.70원 | +2,858.40원 |
| 263020 | +277,736.87원 | +264,361.16원 | +5,286.78원 | 0원 | +300,450.96원 |

두 사건 모두 동일 진입·만기의 단순 보유와 손익이 같았다. 큰 수익을 낸 263020은
단순 추세와도 같고, 최초 판단 이전 20관측 세션 수익률이 +6.25%였다.
이벤트가 가격 추세 위에 더한 가치라고 식별할 수 없다. BASE 양의 순손익 중
99.29%가 이 한 회사/진입일에 집중된다. 두 사건 모두 사전 정의 하락 국면이 아니다.

023150의 개장가 모델 전 총 가격손익은 2,730원이다. 수수료 24.94원, 세금 85.78원,
체결가격에 포함된 슬리피지 41.58원, 운영비 600원을 한 번씩 반영해 1,977.70원이 남았다.
이 사건의 최대 종가 주식 노출은 약 0.43%로, 전일 거래량 용량 제한 때문에 목표 .25를
실제로 채우지 못했다. 자본 점유 대비 수익과 절대 금액을 함께 봐야 한다.

263020은 총 가격손익 287,560원에서 수수료 1,472.21원, 세금 5,192.44원,
슬리피지 2,458.48원, 운영비 700원을 차감했다. 평균 종가 주식 노출은 14.28%,
최대 종가 노출은 **26.39%**였다. 최초 목표 .25라도 가격 상승 후 실제 노출이
상한을 넘은 날이 2일이다. 위험 적격성 통과로 취급하지 않으며 배분은 승인하지 않는다.
같은 위험을 달성한 전략으로 해석하거나 사후 비례 축소로 이를 고치지 않는다.

BASE MDD는 023150 약 0.0035%, 263020 약 1.5864%다. 종가 기준이며 장중 최악 손실을
증명하지 않는다. ES·최악 일손실·회전율·점유율·비용·반환 감쇠는 results.json의 사건별
요약에 기록했다. 시장 방향 기여는 전일 실제 보유량×지수 수익률의 진단 대용값이다.
거래 가능한 시장 상품이나 업종/PIT 요인에 대해 위험을 정합한 초과수익은 아니다.
업종 기여와 실제 장중 체결 품질은 자료가 없어 NULL이다.

PARTIAL에서 각각 1주와 41주가 남았고, 위험감축 미이행을 그대로 기록했다.
청산 주문 제출, 모델 체결, 잔여 수량을 구별했으며 종말 강제 체결로 손익을 개선하지 않았다.
5관측 세션 보유 등 다른 만기는 탐색하지 않았다. D1은 동결한 5일 달력 만기다.

독립 회사 2개·진입일 2개·하락 사건 0개로 최소 30사건/10회사/20진입일/5하락 사건에
미달한다. 따라서 군집 CI·Holm 검정은 미실행/NULL이며 유의성을 주장하지 않는다.
기업/날짜/사건군 상관이 없다고 보지 않는다. 원래 A0·A1·EWY 결과는 바꾸지 않았다.
사후 필터를 붙여 같은 두 사건에서 더 나은 전략을 고르지 않는다.

결론적으로 가격 반응은 관측됐지만 이벤트 고유의 반복 가능한 경제성, 하락장 재현성,
위험 정합성과 실제 실행 가능성은 확인되지 않았다. 수집 간격 미준수도 독립적으로 남는다.
`ECONOMIC_EDGE_UNVERIFIED` / `LIVE_NOT_APPROVED`.
