# DF-004 preregistered EWY lead-lag protocol

이 문서와 `artifacts/df004/DF004_PROTOCOL.json`은 새 EWY 결과를 보기 전에 별도 커밋·정상 push한다. 시작 SHA는 `daefa1d8f6c6ec34279b1c4b7a401ffedd6c83ad`다. 기존 한국 6종목·1년 구간은 이미 소비한 탐색 자료이며 확인적 OOS가 아니다.

## 질문과 시간 경계

EWY 정규장 몸통 `close/open-1`의 부호가 다음 한국 세션의 **개장 이후** 수익에 추가 정보를 제공하는지 검증한다. 한국 전일 종가→당일 시가 갭은 신규 시가 매수자의 수익으로 계상하지 않는다. 실제 09:05 자료가 없으면 그 성과는 NULL이다.

실제 미국 세션·휴장·조기 종료와 America/New_York DST를 검증하고 UTC→Asia/Seoul로 정렬한다. 완료된 미국 세션을 그 정보가 가용한 뒤 첫 한국 적격 결정(08:00)에 대응시킨다. 여러 미국 세션이 한국 휴일 뒤 같은 날에 대응하면 최신 세션만 사용한다. 미국 휴장 뒤 이미 사용한 세션을 반복하거나 가상의 미국 거래일을 만들지 않는다. 기존 한국 특수 세션 2025-11-13·2026-01-02는 정규 개장 모델에서 제외한다.

실제 취득시각과 과거 공개시각을 구분한다. strict 경로는 공개시각 증거를 요구한다. 별도 가격-only 탐색 경로는 미국 정규장 종료+60분이라는 보수적 **모델 가정**을 사용할 수 있지만 `HISTORICAL_PUBLICATION_UNVERIFIED`를 유지한다. 실제 가용시각을 소급 생성하지 않으며 G1/OOS로 승격하지 않는다.

## 고정 모델과 비용

모델은 CASH, ALWAYS_LONG, DOM_STOCK, DOM_INDEX, H1_EWY, EWY_AND_DOM_INDEX, EWY_AND_DOM_STOCK, EWY_DELAY_ONE_US_SESSION 8개다. 국내 대조는 전일 종가 수익률 부호, EWY는 완료된 최신 미국 세션 몸통 부호, 결합은 AND다. 롱 신호는 독립 연구자본 1,000만원의 목표 25%, 그 외 0이다. 공매도·인버스는 없다. 업종·SOXX·FX 자료가 없으면 만들지 않는다.

6종목 × 8모델 × BASE/STRESS = 96개 독립 Reference를 계획한다. 일 운영비 100원, 현금 이자 0, BASE 수수료/매도세/슬리피지 3/20/5bp, STRESS 10/30/20bp다. 실제 계약값이 아닌 연구 추정이다.

기존 ReferencePortfolio 회계를 재사용한다. 전일 NAV/종가로 수량과 매수 지정가(+5%)를 정하고 전일 거래량 0.1%로 수용량을 제한한다. 시가+1초 및 종가+1초의 가격 anchor는 **실제 Tick이 아닌 탐색 가정**이다. 종가 청산은 15:19에 목표0·전일 종가70%의 매도 한도를 정한 것으로 모델링한다. 실제 경매 체결을 보장하지 않는다. 주문은 1분 후 만기, 매도대금은 T/T+1 재사용 금지다. 감축 미이행은 신규 진입을 차단하고 HOLD로 남기며, 잔여 보유의 갭 손익은 신규 시가 진입 수익과 별도 분해한다. 강제 말기 청산은 없다.

## 통계·반증과 판단

국내 6종목을 같은 날의 독립 표본 6개로 늘리지 않는다. 날짜별 평균은 통계 진단용이며 실제 공동계좌가 아니다. BASE의 3개 사전 endpoint는 (1) EWY 양/비양 날짜의 한국 몸통 차이, (2) EWY+국내지수와 국내지수의 날짜별 비용 후 차이, (3) EWY+국내주식과 국내주식의 차이다.

날짜 단위 circular moving-block bootstrap(5일 블록, 1,000회, seed404), percentile 95% 구간과 중심화 양측 bootstrap p를 사용한다. 3개 endpoint에 Holm α=.05를 적용한다. 최소 80개 공통 날짜와 EWY 양/비양 각각 20개 날짜가 필요하다. 독립 표본의 신뢰구간이나 무작위 train/test 분할로 포장하지 않는다.

SUPPORTED는 유의한 양의 몸통 효과와 적어도 하나의 양의 추가정보 endpoint, H1 현금 초과 BASE/STRESS 각각 4/6 이상, EWY+지수의 지수-only 개선 4/6 이상, 양의 날짜 기여 중 상위5일 비중 50% 이하를 모두 요구한다. 충분한 자료에서 미충족이면 NOT_SUPPORTED, 표본 부족이면 INSUFFICIENT_EVIDENCE, 실제 EWY OHLC·달력/접근 장애면 DATA_BLOCKED다. SUPPORTED도 탐색 근거일 뿐 경제성·실전 승인이 아니다.

반증은 미래 미국 자료를 잘못 연결한 validator 차단, 실제 미국 1세션 지연 placebo, 항상 롱/현금, 국내-only, 비용 악화, 전일20지수 수익률 ±5% 구간, 종목·월 제외 및 상위5일 집중도를 포함한다. 사후 평균 노출 비례 정합은 POSTHOC_DIAGNOSTIC만 허용하며 실제 위험 정합이나 자본배분에 사용하지 않는다. 잘못 정렬한 미래정보 모델은 채택 대상이 아니다.

## 데이터·승인과 NAV

EWY NYSE Arca의 실제 제공 가능 시장코드·TR·조정·페이지네이션은 공식 규격과 실제 응답으로 확인한다. 이 프로토콜 자체는 새 KIS 인증 요청을 승인하지 않는다. 필요한 종목·기간·API·페이지·인증·재시도 포함 상한을 별도 제시한다. 기존 캐시와 공개 비인증 자료도 먼저 확인한다.

NAV는 별도 경로다. 기준시각·공정가치 조정·환율·실제 공개시각·정정 이력이 없으면 NAV_PUBLICATION_UNVERIFIED로 남긴다. NAV 부족이 가능한 가격-only 경로를 막지 않는다. 기존 Alpha A·DF-001~003·Risk·OMS·Ledger를 바꾸지 않는다. 원시 미국/한국 자료는 private store에만 둔다.
