# KM-005 데이터 적격성 및 최소 보완 경로

확인일 2026-10-17 KST. 평가 목적은 비공개 Alpha A 연구다. 신규 인증·시세 API 호출은 0회다.
현재 실제 가격 파일은 저장소 밖으로 전송하지 않고 기존 로컬 자료의 무결성과 메타데이터만 점검했다.

## 권한별 확인 결과

사용자가 제공한 [KIS 서비스 이용안내](https://apiportal.koreainvestment.com/about-howto)를 조사했다.
동적 화면 본문은 웹 텍스트 추출에서 표시되지 않아 안내 페이지의 공개 footer가 사용하는
[고객 약관 API](https://apiportal.koreainvestment.com/api/terms/public?termsType=MARKET)를 읽었다.
인증과 무관한 공개 문서 GET이다. 문서명은 오픈 API 서비스 이용 약관(고객), 본문 제정일은
2022-08-08, 공개 API version 28, lastModifiedDate는 2024-04-11T16:10:59+09:00이다.
원문 응답 SHA-256과 확인일은 `artifacts/km005/license-source-proof.json`에 보존했다.

제5조 제3항은 시세의 고객 개발 프로그램 등 개인 업무 이용을 명시하고 제3자 제공을 제한한다.
따라서 개인 프로그램 이용 및 전략 개발 범위의 근거는 확인했다. 이는 저장·백테스트가
금지됐다는 뜻도, 모든 연구·장기 보관이 승인됐다는 뜻도 아니다.
현재 사용자에게 적용되는 계약·추가 공지와 장기 저장 범위는 독립 확인하지 못했다.
2026-10-06 데이터 이용 정책 FAQ 제목은 검색 결과에 있으나 직접 본문을 확보하지 못했다.
확인된 공개 약관 버전을 최신 개인 적용 계약으로 단정하지 않는다.

| 사용 목적 | 상태 | 근거·한계 |
|---|---|---|
| 개인 개발 프로그램 이용 | CONFIRMED | 공개 고객 약관 제5조 제3항의 범위 |
| 개인 자체 전략 개발 | CONFIRMED | 개인 프로그램 범위, 실전 주문 승인과 별개 |
| 비공개 분석·내부 백테스트 | UNVERIFIED | 목적의 구체적 적용 여부와 조건 미확정 |
| 장기 로컬 저장 | UNVERIFIED | 보관기간·계약 종료 이후 이용 범위 확인 필요 |
| 원시 데이터 공개·제3자 데이터 제공 | PROHIBITED | 공개 고객 약관 제5조 제3항 |
| 가공 데이터 외부 공개 | UNVERIFIED | 가공 수준·원정보 복원 가능성 포함 별도 확인 |
| 상업 서비스·제3자 대상 제공 | UNVERIFIED / 제공 제한 | 제휴·거래소 계약 확인 필요 |

전체 내부 연구 범위를 `LICENSE_UNVERIFIED`로 유지한다. 코드 예제의 라이선스를 시세 권리로 쓰지 않는다.

## 공급원 비교

아래 미확인은 결함이 없다는 뜻이 아니다. 최대 제공기간이나 견적을 임의 추정하지 않았다.
수년의 목표 범위는 3~5년 이상을 후보로 검토하되, 독립 사건·시장 국면·보유기간을 보고 결정해야 한다.

[KRX OPEN API 약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)은
2025-12-26 시행 표시이며 비상업적 이용, 제3자 제공 제한, 승인 기간 등을 명시한다.
이 사실만으로 개인 자동매매 연구의 분류를 확정하지 않는다.
[KRX 구매 안내](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA001.jsp)는 결제·목적 심사를 안내한다.
상품 구매나 신청은 하지 않았다.
[OpenDART 소개](https://opendart.fss.or.kr/intro/main.do)와
[약관](https://opendart.fss.or.kr/intro/terms.do)을 확인했다. 공시 원문·재무정보이며 OHLCV 공급원이 아니다.

## 실제 품질 결과

RAW/ADJUSTED 각 60행, INDEX 60행, 총 180행. 실제 독립 주식 날짜는 60개다.
기간 2026-07-20~10-16, 주식 005930, 지수 0001, KRX 일봉.
이전 실제 4행은 같은 날짜에 포함되며 별도 표본으로 가산하지 않았다.
동일 종류·종목·일자·venue·가격기준의 중복/상충 키 0, 주가 거래대금 누락 0.
4개 데이터셋의 원본·정규화·manifest 해시와 수집 시각·parser 버전을 대조했다.
이는 가격의 역사적 정확성·정정 없음·PIT 적격성을 증명하지 않는다.

세션 미검증, 수정 이력 미검증, 과거 지수 공표시각 미검증 flag가 남는다.
일봉이 날짜 정밀도여서 event_time·bar interval을 임의 생성하지 않았다.
과거 release 자료가 없으므로 available_at을 수집 이전으로 소급하지 않았다.
당시 master, 상폐/상장 전후, 거래정지, 업종 이력, 기업행위는 미확보다.
예상 거래일 분모가 없어 결측률은 null이다. 지수와 종목 관측일의 일치가 전체 달력 완전성은 아니다.
원주가 60행은 기존 Alpha adapter에서 모두 거부됐다. 이 차단을 제거하거나 quality flag를 지우지 않았다.

## 공식 문의 초안 및 최소 다음 단계

다음은 문의 문안이며 실제로 발송하지 않았다.

1. 개인 API 시세로 비공개 전략 백테스트와 내부 연구를 수행하는 것이 개인 업무 범위에 포함되는가?
2. 원시·정규화 데이터의 로컬 저장 가능 기간과 이용 종료 후 보관·재사용·삭제 조건은 무엇인가?
3. 소스 코드·해시·집계된 검증 결과 공개의 허용 범위와 가격 재구성 제한은 무엇인가?
4. 상폐·정지·시점 universe·기업행위·정정 전 버전·최초 공표시각의 제공 범위는 무엇인가?
5. 대상 기간·종목·빈도별 유량·연속조회·장기 보관 권한 및 추가 비용은 얼마인가?

우선 약관 적용과 필요한 데이터 상품 범위를 문의하는 편이 불확실한 대량 조회보다 비용이 낮다.
KIS의 프로그램 이용 허용을 근거로 대규모 추가 수집을 시작하지 않았다.
권한·PIT 제공 가능성이 확인된 뒤 표본 범위, 날짜, 최대 요청량, 저장 위치를 명시해 새 수집 승인을 받아야 한다.
그 후 capital·risk·비용 계약과 OOS 구간을 동결해야 한다. 현재 사용자 자본·위험 승인값을 대신 정하지 않는다.
