# DF-003 execution robustness

**1주 잔존 문제는 미해결이며 `RISK_REDUCTION_HOLD`다.** 기존 PARTIAL 모델과 원본 결과를 보존했다. 유리한 잔량 체결, 새 `PARTIAL_EXECUTION_MODEL_V2`, 확률적 체결 보정은 도입하지 않았다. 실제 매매 가능성을 확인한 자료가 없으므로 자동 위험감축 완료를 보장하지 않는다.

## 독립 경계 점검

모델의 50%는 `floor(remaining_quantity × .5)`라는 결정적 수량 비율이다. 체결 확률 50%나 시장 자료로 보정한 분포가 아니다. 잔량 3→2→1 이후 `floor(1×.5)=0`으로 더 이상 매도되지 않는다. 1주 최소 단위, 1분 주문 만기, 다음 결정의 재제출을 별도로 시험했다. 주문이 EXPIRED여도 보유주식은 없어지지 않는다. 새 시험은 3주 포지션의 두 번 매도 후 1주가 남고 활성 주문은 0인 상태를 확인한다.

관측된 거래정지가 있다는 가정의 합성 Tick은 양의 수용량이 있어도 `executable=False`로 체결되지 않는다. 이는 실제 표본에 정지 자료를 추가했다는 뜻이 아니다. 실제 표본의 개장 호가·정지 상태는 UNKNOWN이다. `UNKNOWN`·`MODEL_ONLY`의 실제 실행 가능성은 NULL, 별도로 증거가 있는 `HALTED`는 false로 표현한다.

강제 위험감축 요청도 아직 보유수량이 남으면 HOLD다. 가상 진단은 UNKNOWN/HALTED/MODEL_ONLY × 미결 수량 0/1의 6가지 상태를 점검했다. 강제 요청이라는 이유로 가격·대기열·정지·정수 제약을 건너뛰지 않는다. 실제 브로커 주문을 발생시키는 기능이 아니다.

## 실제 저장 자료를 사용한 결과

A0 PARTIAL의 6종목 최종 잔여는 모두 1주이며 기존 V3와 전체 결과가 같다. A1·A2·A3 PARTIAL도 6종목 모두 최종 위험감축 미이행 HOLD다. 후보 변경으로 이 체결 경계가 해결됐다고 주장하지 않는다. A0 삼성전자 최종 평가손익 40,373.94원은 그대로이며, A1도 동일하다. A2·A3는 164,126.61원이지만 강제 청산할 수 있는 확정 이익이 아니다.

이번의 `unfulfilled_reduction_days`는 **매일 목표 0이고 체결 후 보유수량이 양수인 모든 날**이다. 마지막 1주만 센 DF-002의 199일과 정의가 다르다. 삼성전자 A0는 203일, A2·A3는 188일이다. 만기 잔량 합은 반복 재제출을 중복 포함하므로 고유 주식 수로 해석하지 않는다. 활성 주문 0과 잔여 보유 1주를 구분한다.

BASE/STRESS 삼성전자 A1에도 2일의 일시적 감축 미이행이 있었고 최종 잔여는 0이다. `NO_UNFULFILLED_REDUCTION`은 **말기**에 미이행이 없다는 뜻이며 과거의 미이행 일수를 지우지 않는다. 최대 5/20 관측 세션은 의사결정 규칙일 뿐, 실제 체결을 강제하는 물리적 보장이 아니다.

## 비용과 상태 보존

수수료·세금은 기존 Ledger의 결합 반올림을 한 번만 반영한다. 수수료를 별도로 나누고 남은 반올림 차이를 세금에 배분한다. 슬리피지는 체결가에 내재되어 있으므로 다시 차감하지 않는다. 운영비는 하루 100원이며 시장충격 비용을 별도로 만들어 더하지 않았다. 미체결 주문의 만기는 취소 API 호출이 아니다.

연구 분류 RETAIN/REVISE/REJECT와 실행 안전 HOLD는 분리한다. 이 단계에서 정수 버림을 억지로 올림해 청산하거나 미검증 호가를 만들지 않았다. 향후 체결 모델을 바꾸려면 잔여 처리·요청량·체결자료·분포·시드·반복 수를 별도 사전 등록해야 한다. 자료 없이 실제 체결 가능성을 확정할 수 없다. 중앙 Risk·OMS·Ledger는 변경하지 않았고 이 Reference는 위험 엔진이나 LIVE 승인을 통과한 주문이 아니다.
