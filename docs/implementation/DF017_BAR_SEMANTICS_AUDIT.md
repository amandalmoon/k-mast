# DF-017 분봉 의미 감사

실제 응답이 없어 의미 검증 결과는 미확정이다. 원문의 필드명만으로 START/END 라벨이나 확정 게시시각을 채우지 않는다. DF-016 `B_BAR_ORB_V1` 코드·실험 결과는 그대로 보존했다.

분봉 진단기는 원문 SHA에 연결해 `stck_bsop_date`, `stck_cntg_hour`, 시가/고가/저가/현재가 및 `cntg_vol`을 검사한다. UNKNOWN 라벨이면 start/end를 NULL로 둔다. 날짜·숫자·OHLC·중복·미래 query·진행 봉·0거래량·첫 체결 미확인 flag를 보존한다. 파싱 종료 이후 검증 완료시각을 찍고 정규화 행의 가용시각을 그 시각으로 맞춘다. 가격을 공급자 시각에 이미 알고 있었던 것으로 소급하지 않는다.

09:05/09:06 및 09:15/09:16의 동일 라벨별 가격·거래량 변화를 private `requery_changes()`로 비교할 수 있다. 전후 원문 해시와 달라진 필드를 보존하고, 값이 같아도 `correction_finality_verified=False`다. 현재 변경 건수·관측 봉수·최초/마지막 시각은 실측이 없어 NULL이다.

FHPST01060000은 보조 체결 자료다. 시각·가격·체결량·누적량·bid/ask의 존재와 타입을 검사하며, 문서/실제 표기 차이를 임의 수정하지 않는다. 소스 영업일·고유 sequence·독립 첫 체결 완전성이 없으면 FIRST_TRADE_UNKNOWN이다. 전체 틱 스트림을 확보했다고 표시하지 않는다.

호가는 접수시각·bid/ask·잔량과 제공되는 시장/VI 필드 목록을 별도로 남긴다. 날짜가 독립적으로 확인되지 않으면 연구 적격은 HOLD다. 현재 공급 진단은 모든 관측 컨텍스트의 시장·정정·라벨·첫 체결 의미를 UNKNOWN으로 유지한다. 필수 의미가 공식 근거와 실제 관측으로 확정돼야 후속 검토에서 별도 연구 컨텍스트를 구성할 수 있다. 현재 코드가 JSON 체크박스로 이를 자동 통과시키지는 않는다.
