# B_BAR_ORB_V1 연구 계약

이 계약은 기존 B_TICK_ORB의 수정이나 대체 승인이 아니다. 네트워크·브로커·OMS·실제 주문 기능이 없는 `kmast.data.bar_orb`에서 분리 구현했다. 범위는 개장 5/15개 완성 1분 구간의 고저가와 이후 완성 분봉 종가의 돌파 **후보**다. 분봉 고가 도달 순서, 틱 돌파 순간, 같은 가격의 체결 가능성은 추론하지 않는다. 비용·손익·포트폴리오 배분·OOS PASS는 계산하지 않는다.

## 여섯 시각

거래소 개장시각은 독립적으로 검증된 세션 입력이다. 원문의 라벨시각은 그대로 보존한다. 실제 분봉 종료는 START/END 의미를 독립적으로 확인한 경우에만 계산한다. HTTP 요청 시작과 전체 응답 완료는 별개이며, 파서 검증 완료는 그 이후다. 최초 신호 가용시각은 사용한 모든 입력의 검증 완료시각 중 최댓값이다. 예를 들어 09:06 종료 봉을 09:16:10 요청, 09:16:11 응답, 09:16:12 검증했다면 후보는 09:16:12부터 알려진다. 09:06으로 소급하지 않는다.

범위는 `[open, open+5/15분)`의 정확한 슬롯 수를 요구한다. 요청 전에 봉이 끝나지 않았거나 미래 query·미래 행·비분 경계·다른 영업일·누락·중복·수정·0거래량·첫 체결 전 거래량·미확인 세션/시장/정정/시계/가격 및 수량 매핑이 있으면 적격 결과는 NULL이다. 잘못된 OHLC/숫자/응답 구조는 입력 값을 노출하지 않는 오류로 거부한다. 원문의 누적 거래대금을 분봉 거래대금이나 VWAP로 바꾸지 않는다.

BarLedger는 모든 수신 버전을 보존한다. 동일 내용 재조회는 최초 가용시각을 유지하고, 변경된 버전은 정정 관측 이후의 view에서 차단한다. 나중에 알게 된 정정을 과거 as-of에 미리 반영하지 않으며 이전 신호를 다시 개선하지 않는다. 합성 oracle은 실제 관측을 적격으로 만들 수 없고 합성/관측 계보를 섞지 않는다.

## 호가의 의미

호가는 독립된 HTTP 응답이다. 신호 가용시각 **뒤에 시작한** 요청과 신호 이후의 공급자 호가시각을 모두 요구한다. 가격 응답과 함께 받은 과거 호가는 후속 호가가 아니다. 공급자 접수시각은 초 단위이며 날짜 필드가 없으므로 독립 세션 날짜에 결합한 근거를 명시한다. 소스 날짜가 있었다고 주장하지 않는다. 미확인 날짜/시장/시계, 미래·노후 호가, 역전 스프레드, 다른 종목은 차단한다. 2초 최대 source/응답 차이는 연구용 보수적 기준이며 실측 지연 추정이 아니다.

후속 스냅샷이 유효해도 `is_fill=False`, `execution_verified=False`다. 호가에 실제 거래가 가능했는지, 잔량이 유지됐는지, 주문이 들어갔는지, 체결이 됐는지는 알 수 없다.

## RVOL·보관

RVOL은 동일 종목·동일 5/15분 창·KRX·동일 계약으로 적격인 이전 20개 실제 거래세션과 해시 계보가 필요하다. 중복 날짜·당일/미래 날짜·다른 종목/창·미확인 자료를 섞지 않는다. 적격 세션 목록은 독립 캘린더와 수집 증거로 구성해야 하며 단순 과거 달력 20일을 사용하지 않는다. 테스트 oracle의 합성 날짜는 소프트웨어 검사 전용이다.

현재 실제 세션은 0개이므로 RVOL_NOT_READY다. 당일 API를 소급 호출해 20세션을 만들 수 없다. 공식 역사 분봉 샘플 FHKST03010230은 실전 자료의 120건·최대 1년을 안내하지만 PAPER 지원 근거가 확립되지 않았고 기존 차단도 유지한다. 대안은 별도 승인한 미래 20세션의 동일 창 수집 또는 별도로 권한·시간·수정 계보를 확인한 역사 공급이다. 이번 한 번의 파일럿으로 RVOL 준비를 주장하지 않는다.

보관 제안은 해당 날짜 원문·정규화·요청/응답/검증 시각·해시를 Git 제외 private store에 최대 30일이다. 당일 조회 가능 범위와 로컬 보관 권한은 다른 문제다. 제공자 권한 확인과 인간 승인이 선행돼야 하며 현재 자동 수집/삭제 작업은 없다.
