# DF-002 causal replay audit

판정: **DF002_CAUSAL_REPLAY_VERIFIED**, 범위는 선언된 개장가격 가정 아래의 오프라인 탐색 재생이다. 실제 개장 체결 가능성·과거 PIT 적격성·확인적 경제성을 검증했다는 뜻이 아니다. **EXPLORATORY_REAL_DATA / ECONOMIC_EDGE_UNVERIFIED / LIVE_NOT_APPROVED**를 유지한다.

## 기준선과 보존

원격·로컬 시작 SHA `3e3e2d867d69c6a9adae9343b0d55d4662088084`를 확인하고 기존 312개 시험을 재실행했다. 원본 사양, Alpha A config·features·decide, OMS·Risk Engine, 기존 보고서·수집자료·V2 72개 파일을 변경하지 않았다. `artifacts/df002/preflight.json`에 시작 바이트 해시를 보존한다. 추가 인증·시세·계좌·주문·취소 요청은 0이다.

## A1: metadata 미래 의존성

V2의 `source_version`은 전체 주식 패널의 record ID를 해시했다. 미래 관측을 append하면 과거 Context와 snapshot identity가 달라질 수 있었다. 이는 **신호 식별자·메타데이터의 미래 의존성**이다. 당시 가격·목표수량을 미래 가격으로 계산했다는 증거와는 구분한다.

V3는 의사결정에 실제 전달되는 전일 종료까지의 21개 주식·지수 봉을 각각 직렬화해 `input_hash`를 생성한다. 전체 취득 manifest hash는 별도 계약에 보존한다. 각 결정은 원 record ID, 지수 record ID, 가정된 가용시각, 마지막 가격일, intent·evidence refs를 비공개 lineage에 기록한다. 신호 identity에는 별도 전달되는 보유 상태도 포함시켰다. 이는 가격만 같더라도 보유 상태가 다른 결정이 같은 식별자를 갖는 문제를 방지한다.

미래 append, 미래 가격·record ID 수정, 당일 개장가·종가 변경 시험에서 공개 이전의 과거 신호·이유·목표·evidence·identifier 불변을 확인했다. 원본 provenance는 실제 취득 당시의 사후 자료임을 유지한다. 날짜 경계와 다음 관측일 가용시각은 탐색 가정이며 알 수 없는 실제 과거 공개시각을 복원한 것이 아니다. 원본 품질 flag를 삭제하지 않는다.

## A2: 개장 체결 모델

V2는 09:00:01 모델 이벤트의 executable 판단에 당일 최종 거래량을 사용했다. 이는 개장 당시 알 수 없는 정보다. V3는 이를 제거했다. 전일 거래량의 0.1% 수용량 상한과 주문 잔량×시나리오 체결비율을 버림한 정수 수량을 사용한다. 전일 종가±5% 지정가와 비용을 반영해 조건이 맞으면 시가를 가상 체결 anchor로 사용한다.

이 이벤트는 호가·체결 Tick 관측이 아니다. 내부 ReferencePortfolio 인터페이스에 전달하는 **ASSUMED_OPEN_ANCHOR_NO_QUOTE_TRADE_OR_HALT_PROOF / UNVERIFIED** 모델이다. 당일 거래정지·개장 거래·대기열 자료가 없어 실제 체결 여부는 NULL/미검증이다. 최종 거래량이 0이어도 모델 결과를 동일하게 유지하는 회귀시험을 추가했으며, 이것은 실제 무거래 종목에 체결을 보장한다는 뜻이 아니다. 당일 시가가 지정가를 벗어나면 가상 체결도 하지 않는다.

## A3: 규칙과 경제성 보존

기존 `features()`를 그대로 호출하고, 돌파·상대강도·거래대금·변동성 비중·최대 25%·추세 유지·손절·보유기한·추가 매수 금지 규칙을 보존한다. 합성 동일 입력에서 기존 `decide()`와 진입·보유·기한·손절의 목표·이유·evidence를 비교한다. 탐색용 표본 적격성은 기존 PIT/G1/OOS 승인이 아니다.

보유기한 `P5D`는 **5 달력일**이며 5거래일로 바꾸지 않았다. 주말·관측일 공백 때문에 실제 청산 가능한 첫 관측 세션까지 기간이 길어질 수 있다. T/T+1 매도대금 재사용 차단, 1분 주문 만기, 1주 단위와 부분체결 버림도 유지한다.

## V2 / V3 비교

고정된 이전 소스로 V2 72개 전체를 다시 실행해 전체 canonical 결과가 일치함을 확인했다. 원본을 다시 쓰지 않았다. `v2-reproduction.json`은 이전 소스 및 72개 파일 해시와 완전 비교 증거다. `run_df002.py --reproduce-v2`로 재실행할 수 있다.

V3의 동일 72개 비교에서 **경제적 주문·체결 모두 일치, 순손익 차이 모두 0원**이다. 주문 식별자 1,262개는 인과적 입력·보유 상태 hash로 바뀌었다. 최종 90개 재생의 결정 계보는 20,070개다. 보관 표본에서 전일 정보로 정한 주문의 가격·수량은 바뀌지 않았고, 당일 최종 거래량 제거도 이 표본의 경제적 체결을 바꾸지 않았다. 따라서 V3가 항상 V2와 같은 경제 결과를 낸다는 일반적 보장은 하지 않는다.

최종 V3는 단순 추세 기준선 18개를 추가해 90개다. 초안과 최종 결과를 비공개 별도 폴더에 보존했다. 리뷰 과정에서 추세 기준선 청산 이유를 Alpha A의 기한으로 표시하지 않도록 고쳤고, MFE/MAE 종가 proxy에서 개장 청산 이후의 당일 종가를 제외했다. 이는 분석 라벨·보유기간 측정 수정이며 경제적 재생 결과를 바꾸지 않았다.
