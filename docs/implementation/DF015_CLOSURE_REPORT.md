# DF-015 종료 보고

**DF015_TRANSPORT_PROTECTION_PENDING / B_ORB_STREAM_TRANSPORT_BLOCKED**.
공식 로컬 캐시에서는 PAPER의 평문 WS 주소와 승인키 사용 방식을 확인했으나 공식 암호화 경로를 확인하지 못했다. 최신 서비스 전체의 부재를 단정하지 않는다. 새 네트워크 자료 조회·인증·WebSocket·TLS 시험·실제 프레임·계좌 조회·주문·취소·LIVE는 모두 0이며 실행 예약도 없다.

DF-014의 문서 boolean/파일 SHA 검사와 실제 평문 연결 사이의 결함을 수정했다. CLI는 문서·환경 로딩 전, 수집기는 키 발급 전, 직접 connector·send는 전송 전에 보호 경로를 요구한다. 검증된 공식 경로가 없는 이 버전에서는 항상 거부한다. 위조 문서·VPN 주장·임의 wss 변경으로 실행을 열 수 없다. 실제 TLS 연결을 구현하거나 검증한 것으로 보고하지 않는다.

대체 공급원 비교·문의 초안은 준비했지만 서비스·비용·보관권을 검증한 대안은 없다. **가장 저렴한 적격 공급원은 아직 결정할 수 없다.** KIS 서면 답변을 우선 확보하고 미충족 시 동일 요구로 공식 후보의 계약·견적을 비교해야 한다. 문의는 전송하지 않았다.

합성 성능/장애 시험은 실데이터 공급 검증과 분리했다. 실제 ORB5·ORB15·VWAP·수익률은 NULL이다. 시장상태·정정·개장 완전성·시계 오차와 RVOL 미준비로 연구 HOLD를 유지한다. 원래 동결 파일럿 종료 후에는 `DF014_MISSED_OBSERVATION_WINDOW`로 판정하며 재예약하지 않는다.

## 검증 증거

기존 608개 사례를 유지하고 새 29개 보안·장애 사례를 추가했다. 기존 네 합성 테스트에서만 새 gate를 명시적으로 mock하여 원래 응답/예산 검사를 보존한다. 운영 gate의 차단은 별도 신규 테스트에서 mock 없이 확인한다. 전체 637개와 기존 608개 회귀가 통과했다. 각 명령 종료코드는 `artifacts/df015/checks.json`, pytest 로그·JUnit에 기록한다. 테스트 수는 경제성 증거가 아니다.

전체 pytest, 608개 회귀, Ruff, format, strict mypy(91개 소스), sdist/wheel, OMS/Alpha/joint 회계 재생, V2/V3 및 DF003–014 읽기 전용 독립 검사, 오프라인 장애/공식 캐시 평가, 바이트 보존·비밀정보 검사를 포함한 **31개 명령 모두 통과**했다. 기존 22,007개 비공개 파일의 사전 해시 snapshot 대조와 이전 명세·프로토콜·결과 보존도 통과했다. 비밀정보 검출은 0건이다. 허용된 기존 변경은 수집기·CLI, 네 테스트의 명시적 합성 mock, 검증·CI 통합뿐이다. 원문·세부 합성 장애 자료는 Git 제외 private store에 있다.

프로토콜은 별도 `7c8d5aa18f03817cb0977827badf5fb6eca3d43d`로 먼저 push했다. 최종 변경은 `codex/df015-secure-market-data-gate`에 정상 commit/push하며 정확한 최종 SHA의 Python 3.11/3.12 CI를 확인한다. 완료 여부는 최종 SHA의 CI 상태를 함께 확인한다. Force push·배포·PR 병합은 하지 않는다.
