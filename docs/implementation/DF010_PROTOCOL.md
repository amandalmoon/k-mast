# DF-010 preregistered protocol

The machine-readable protocol is artifacts/df010/DF010_PROTOCOL.json. Targets, source hashes, causal boundaries, five-calendar-day holding, cost assumptions, qualification gates and controls are frozen before inspecting new price outcomes.

This is a three-event technical pilot. Existing caches are audited first. New PAPER authentication and market-data collection require separate explicit approval; the proposed 20-request budget is not approval.

Each qualifying event may replay independently. Full corporate-action and halt histories and publication seconds remain unknown. A constant price-basis ratio is a bounded diagnostic, not proof of a complete corporate-action history. Unknown material action discontinuities remain HOLD. Actual execution and economic edge remain unverified; LIVE remains unapproved.
