# DF-003 frozen research protocol

`artifacts/df003/DF003_PROTOCOL.json`을 새 실험 전에 동결한다. 시작 SHA는 `9b10bbea55d9e74ca9ae0754e6fce91ee433074b`다. 이미 본 6개 생존 종목·223세션은 소비된 탐색 표본이며 확인적 OOS가 아니다.

## 단일 규칙 변화와 대조

- A0: 기존 candidate-v1·V3 그대로. P5D는 5달력일이다.
- A1: 실제 첫 진입 이후 완료된 적격 관측 세션 5개를 센 뒤 다음 모델 개장에 청산한다. 나머지 A0 규칙을 유지한다.
- A2: P5D를 제거하고 기존 20종가 이동평균 추세 약화 청산을 유지한다. 기본 5% 손절과 최대 20개 적격 관측 세션을 강제한다. 무제한 보유가 아니다.
- A3: A2에 ATR20×3 추적 청산을 추가한다. 최고 기준은 진입 원가와 완료된 보유일 종가의 최대이며, ATR은 직전 완료된 21봉에서 20개 true range의 산술 평균이다. 다음 의사결정 전에만 갱신한다. A2와 동일 최대 20세션·기본 손절을 유지한다.

A2는 A0의 기존 이동평균 청산을 새로 발견한 규칙처럼 주장하지 않는다. A3는 A2 대비 ATR 추가의 주변 효과도 함께 비교한다. 각 규칙 조합은 1개뿐이고 새 결과를 보고 기간·배수를 바꾸지 않는다.

T0~T3는 각 A0~A3와 같은 청산·비중·RS·거래대금·비용을 사용하면서 **신규 진입의 돌파 조건만** 직전 종가≥직전 20종가 평균으로 바꾼다. 진입 효과는 각 A/T 쌍으로, 청산 효과는 동일 돌파 진입을 가진 A0~A3로 비교한다. 실제 진입 기회는 이전 청산과 정수·미체결 상태에도 영향을 받으므로 완전한 시장 인과 추정이 아닌 통제된 모델 반사실 비교다.

적격 세션은 전일 시점에 완료되어 확인된 stock/index 관측일 중 양의 거래량·거래대금이 있고 기존 체결 제외일이 아닌 날이다. 실제 진입일의 종가부터 1개로 센다. 공식 휴장 달력이나 역사적 거래 가능성을 인증하지 않는다.

## 고정 실험 수와 실행 가정

6종목 × 3비용 × (A 4개 + T 4개 + 기존 기준선 4개) = **216개 독립 Reference**다. BASE/STRESS/PARTIAL 비용·운영비·체결·매도대금 제한은 V3 그대로다. 기존 90개 V3와 A0·기준선의 재현을 연결한다. 별도 실데이터를 수집하지 않는다.

시가 anchor는 실제 체결 Tick이 아니다. 50% 부분체결의 1주 버림·1분 만기·재제출도 그대로 유지한다. 새 확률적 체결 모델이나 유리한 잔량 체결을 넣지 않는다. 강제 위험감축 요청이 이행되지 않으면 `RISK_REDUCTION_HOLD`를 별도 표시한다.

## 노출 및 채택 판단

평균/최대 실제 비중, 보유일, 거래금액, MDD·최악 종가일·일별 NAV 변동성, 종목·지수 베타, 비용·실현/미실현·청산 이유를 비교한다. 같은 종목의 베타와 전략 NAV 베타를 구분한다. 연환산 변동성의 252는 연구상 표시 관례이며 미래 목표 위험을 고르는 입력이 아니다.

노출 정합은 사후 쌍별 평균 비중의 작은 값을 공통값으로 삼고 현금 대비 손익을 비례 조정하는 **POSTHOC_DIAGNOSTIC**만 허용한다. 비용·경로·꼬리 위험까지 같게 만드는 실행 가능한 전략이 아니며 순위 선정이나 실제 자본배분에 사용하지 않는다. 평균 노출이 0이면 NULL이다.

새 후보의 RETAIN은 BASE/STRESS 모두 A0 개선 4/6 이상, BASE MDD 악화 2%p 이내 5/6 이상, 짝지은 진입 대조군보다 좋은 결과 4/6 이상, 반도체 외 4종목 중 개선 2개 이상을 모두 요구한다. BASE와 STRESS 모두 개선이 1/6 이하이면 REJECT, 그 밖은 REVISE다. 누락·회계·보존 실패는 INSUFFICIENT_EVIDENCE다. A0는 동결 비교 기준이며 이 분류로 교체하지 않는다.

이는 다음 탐색 연구에 대한 판단이다. 실제 위험감축·실행 불확실성은 별도 HOLD로 남고, 어떤 분류도 G2/G3나 LIVE 승인이 아니다.
