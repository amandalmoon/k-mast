# DF-016 인과성·보안 감사

새 테스트는 완성 봉의 half-open 경계, HTTP/검증 지연, 미래 query, 진행 봉, 잘못된 날짜·분 경계, 첫 체결 전/0거래량, 수정·허봉·누락·중복, UNKNOWN 캘린더/시장/정정/시계/라벨/가격 및 수량 의미를 검사한다. 원행을 지운 뒤 PASS하지 않는다. BarLedger의 정정 as-of와 최초 관측시각도 검사한다.

동일 요청이나 신호 이전 공급자 호가시각, 노후·미래·시각 누락·다른 종목·역전 호가·미확인 시장은 유효한 후속 스냅샷이 될 수 없다. 유효한 스냅샷도 체결이 아니다. RVOL은 이전 20세션·동일 종목/창·추적 가능한 자료를 요구한다. 합성 컨텍스트의 실제 관측 승격을 차단한다.

`artifacts/df016/synthetic-trace.json`은 명시적 START/시장/정정/시계 oracle을 사용하는 합성 검사다. 09:16:10 요청 → 09:16:11 전체 수신 → 09:16:12 검증 완료 이후에만 ORB5·ORB15 돌파 후보가 생긴다. 09:17의 후속 호가는 스냅샷으로만 분류한다. 합성 가격과 원문 해시는 실제 KIS 결과나 경제성 증거가 아니다. 원문은 private 합성 store에 있다.

새 모듈은 인증·네트워크·브로커·OMS를 import하지 않는다. 문서 조사·결과 생성기도 키를 로딩하지 않는다. KIS 인증/가격 조회·WS/승인키·계좌·주문·LIVE는 0회다. 기존 DF-015의 평문 경로 차단 코드 및 이전 모든 연구 결과는 수정하지 않는다. 실제 데이터를 받기 전 지원·필드·가용성·시장상태를 PASS했다고 기록하지 않는다.
