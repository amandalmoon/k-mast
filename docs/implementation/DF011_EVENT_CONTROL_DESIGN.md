# DF-011 preregistered event-control design

This is a future observational design, not an executed return experiment. It was frozen in protocol commit 40636bc before new issuer evidence. The D1 entry, 25% target, five-calendar-day deadline, stop and cost scenarios remain fixed. The previously observed DF010 cases are consumed exploratory evidence.

Treatment is an original direct buyback decision, acted on only at the first verified eligible session after the date-only publication boundary. BUY_HOLD on the same stock/date is an execution/ledger reference. Equality of those two accounts is expected when their trades coincide; it is not by itself a test of announcement predictability.

For each future event, select exactly three non-event securities from a historically eligible same-market, same-date universe. Require complete relevant disclosure coverage to audit contamination in the frozen [-30,+5 calendar day] window. Post-entry event classification is an ex-post contamination audit and cannot enter the trading signal; missing coverage is UNKNOWN, not no event. Do not fill missing controls with current survivors.

Use only verified predecision features: log median KRW turnover over the prior 20 observed sessions, prior 20-session price return and realized daily-return volatility. Standardize with the eligible cross-sectional median/MAD; drop zero-MAD dimensions. Choose nearest standardized Euclidean distance, tie-break by SHA-256 of receipt and historical standard code. Require all three controls or mark unmatched. Selection has no post-entry return input. Future or unverified feature availability fails closed. PIT industry is optional only with contemporaneous evidence; current industry is not a substitute.

Each account uses the same initial capital, frozen calendar horizon, prices/basis, capacity model, fee/tax/slippage and operating expenses. Report actual exposure and capital occupancy differences rather than scaling returns after observation. Separate market direction, pre-trend/volatility balance, treatment/control residual return, cost/liquidity and investable exposure diagnostics. They do not fully identify causal effects when issuer selection/confounding remains.

No significance testing below 30 events, 10 firms, 20 distinct entry days, 5 declining-market events and 80% admissible matched coverage. Above those minimums, account for issuer repetition, common dates/market shocks and multiple comparisons; raw event count is not independent-experiment count. The inference implementation must be separately frozen before opening future outcomes. Nonpositive cost-adjusted increment versus the preselected controls, or no positive STRESS increment, fails support under this contract. Never relax the match or threshold after results. No tests or new actual control selections were executed in DF011.

The explicit timing clarification in control-eligibility-boundary.json preserves the preregistered protocol and matching thresholds. Rank/filter only on non-event history known before decision, then freeze three identifiers. Audit their later +5-day contamination afterwards. A contaminated or unknown fixed set is unmatched; do not replace any member after that audit. The matching input carries a separate non-event-information availability date. No control set or new expansion outcome has been evaluated, so this clarification cannot select a favorable observed result.
