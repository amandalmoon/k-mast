# DF005 위험감축·장중 실행 후속 실험 명세

기존 DF003 PARTIAL의 1주 잔존은 가상 부분체결의 floor·한도·만료 모형에서 나타난다.
이를 성공 청산으로 바꾸거나 실제 거래정지의 증거로 간주하지 않는다.
이번 단계는 원래 매칭·거래비용·현금·Risk·OMS·Ledger를 변경하지 않는다.

보존할 구분은 위험감축 의도(target0/강제감축), 제출 여부, 체결 수량,
미체결 주문 수량, 만료·거절, 실제 잔고, 청산 실패 일수, `RISK_REDUCTION_HOLD`다.
잔고1주도 잔존 위험이며 손익 계산을 위해 자동 종료 체결을 만들지 않는다.
실제 호가·정지 이력이 없으면 `actual_executable=NULL`이다.

후속 실험은 별도 승인 및 사전 동결이 필요하다. 후보 선정 뒤 국내2종목·서로 다른
유동성 날짜를 정하고 KIS 공식 제공 범위에서 해당일09:00~09:10/청산 의사결정 전후의
분봉·실제 체결·호가를 구분해 수집한다. 과거3년 분봉 제공을 가정하지 않는다.
사용 가능한 `inquire-time-dailychartprice`, `inquire-time-itemchartprice`, 읽기 전용
호가/체결 API 또는 수신 채널의 환경·날짜 제한을 공식 규격과 실제 응답으로 먼저 확인한다.
현 단계의 900요청 승인은 이 경로를 포함하지 않으며 LIVE 인증이나 주문을 승인하지 않는다.

신호 판단시각·주문 의도·승인/거절·호가 확정·데이터 실제 수신시각·최초 실행가능 시각을
별도로 기록한다. 동일한 원래 target/비용/현금 계약 아래에서 관측 체결 여부·잔여 수량·
불리한 가격·큐 불확실성·지연·세션 경계를 평가한다. 데이터에 없는 체결은 NULL/HOLD다.
원래 PARTIAL 결과와 새 실행 버전의 결과는 각각 보존하고 차이를 공개 집계한다.

현재 BUY_HOLD는 원래 V3의 거의 전액 보유 참고선이다. 후보 A0/A1/T의 .25 목표 상한과
위험 정합한 계좌가 아니며 채택 검정의 위험 대조군으로 사용하지 않는다.
프로토콜의 포괄적 '동일 .25 cap' 문구와 이 참고선의 동결 구현 사이의 모호성을 명시한다.
후보 비교는 A1-A0와 A1-T에만 적용하고 BUY_HOLD 규칙을 조용히 바꾸지 않는다.
