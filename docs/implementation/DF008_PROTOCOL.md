# DF-008 사전 문서 파일럿

기준선 `bacfb99360a10249a80a74bfe75132bb725fc195`, **450 PASS**를 확인했다.
문서 내용과 새 가격 성과 확인 전에 `DF008_PROTOCOL.json` 및
`document-targets.json`을 별도 커밋·원격 push하여 동결한다.

620개 D1 원공시에서 2022~2025년 각 15건, 총 60건을 결정적 SHA-256 순위로 선택했다.
연도별 KOSPI/KOSDAQ/시장불명 층을 유지하고 시장불명도 매년 2건 포함했다.
기존 BEAR 표시 7건이 포함된다. 층별 quota/population을 기록했으며 균등한 시장
무작위 표본이나 독립 60실험으로 주장하지 않는다. 2022·2025는 부분 연도다.
같은 법인의 정정 제목 후보 29건을 잠재 연결 검증용으로 추가했지만 연결을 가정하지 않았다.
기존 문서 두 개는 이번 hash 표본에 없으며 별도 오프라인 파서 대조 자료로 재사용한다.

대상은 60+29=89개, 정상 요청 예상 89회, 각 최대 1회 재시도 시 178회다.
전체 제안 상한 200회 이내이며 대상 목록 밖의 문서를 자동 추가하지 않는다.
응답 완료 후 고해상도 3.10초 대기·재검사, 실제 관측 최소 3.05초 미달 시 즉시 중단한다.
대기만 정상 약 4.6분/최악 약 9.2분이고 응답 시간은 별도다.
기존 로컬 `opendart.env`의 키로 GET `/api/document.xml`만 사용할 **제안**이며,
새 명시적 승인 전에는 인증 조회하지 않는다. KIS·계좌·주문·취소는 제외한다.

문서 무결성, 법인 ID, 과거 주식코드, 실제 사건군, 가격/세션 적격성을 독립 판정한다.
AREGCIK 확인은 당시 상장/폐지/정지나 주식코드의 증거가 아니다. 없으면 NULL이다.
정정은 명시적 부모 또는 공식 정정 대상 최초제출일의 유일한 대응만 인정한다.
최초 문서에 나중 정정 값을 소급하지 않는다. D1의 규칙·비용·원장·손익을 바꾸지 않는다.

A 전체 원문 확장, B 최대 3회사 가격 파일럿, C 역사 식별 장애의 성공률·최소 표본은
JSON에 고정했다. 본문을 본 뒤 문턱을 완화하거나 표본을 교체하지 않는다.
