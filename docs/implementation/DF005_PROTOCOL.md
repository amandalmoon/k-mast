# DF005 사전 프로토콜

권위 실행 규칙은 `artifacts/df005/DF005_PROTOCOL.json`에 결과 확인 전 동결한다.
기준선은 `1dd51f6da527efd2a93d799e188f16494ba10759`, 기준 시험386 PASS다.

A0·A1은 기존 구현 그대로, T는 DF003에서 사전 정의한 T1을 사용한다.
동일 자본·비용·상한은 실제 위험 정합을 뜻하지 않는다. A1의 MDD·ES·노출 악화를
성공으로 상쇄하지 않으며 최종 배분과 LIVE 승인은 별도다.

기존 KIS 마스터의 ST그룹·6자리·끝자리0 종목 중 기존6개를 제외하고,
`SHA256('DF005_V1:'+symbol)` 순서로 시장별25개를 선택한다.
ETF를 포함한 전체 마스터를 단순 숫자만으로 표본화하지 않는다.
현재 마스터에 의존한 선택은 생존편향이 있으며 역사적 보통주/PIT 적격성 증명이 아니다.
신규상장·미확보·기업행위 문제로 자료가 부족해도 종목을 사후 교체하지 않는다.

수집 목표는2022-09-01~2025-10-16, 평가 구간은 세 연간 구간이다.
기존 탐색기간과 겹치지 않지만 이것만으로 확인적 OOS가 되지는 않는다.
시장별 순위1~15는 기술구간 종목,16~25는 잠금 검증 종목이며 최종 연간 구간을
시간 검증으로 분리한다. 어느 결과로도 후보 규칙을 조정하지 않는다.

모든 성공·실패 요청의 예산, 응답 완료 후 간격, 원본/정규화 해시와 계보를 보존한다.
원응답이 비밀정보를 포함하면 바이트는 저장하지 않고 hash·크기·고정 사유만 기록한다.
PIT·상폐·정지·기업행위·업종 공표 증거가 없으면 그 공백을 유지하고,
가능한 실제 가격 경제성을 탐색 결과로 보고한다.

이 프로토콜은 인증 수집을 승인하지 않는다. DF004의 인증 한도를 재사용하지 않는다.
별도 승인 전에는 신규 인증·시세 요청 없이 캐시·공식 공개 규격과 오프라인 검증을 진행한다.

프로토콜 세 파일만 별도 커밋·push한 후 신규 가격 결과를 확인한다.
