# DF-007 후속 자료 확보 가능성

현재 판정은 **EVENT_DATA_DEPENDENCY_PENDING**이다. 원공시 후보 620건·301법인·
347모델 진입일·91하락 후보는 사전 공급 기준을 넘는다. 적격 사건은 기존 두 건뿐이므로
새 D1 백테스트는 실행하지 않았다. 표본 자체가 두 건뿐이라는 이유로 추가 연도를
검색할 필요는 없다. 기존 원자료의 식별·문서 의존성을 먼저 해소하는 것이 우선이다.

## 제안 1: 원문과 역사적 식별

기존 D1 원문 2개를 재사용한다. 신규 원공시 618개와 정정 130개, 총 748개
`opendart.fss.or.kr/api/document.xml` 원문 검증을 준비할 수 있다. 요청마다 재시도
최대 1회면 **1,496조회**다. 승인된 조회가 아니며 이번 실행 횟수는 0이다.
계보·실제 취득과 결정·당시 법인/주식코드·상장 상태를 확인하고 미해결은 격리한다.
누락/불명확한 코드 42건과 출처 시장 표기가 불명확한 사례를 현재 마스터로 제거하거나
역산하지 않는다. 확인된 상장폐지 회사 수는 NULL이며 조사 결과에 따라 범위를 다시 확정해야 한다.

## 제안 2: 조건부 가격 조회 산정

원문 검증을 통과할 경우의 종목별 코드·시작/종료일·원/수정 가격·시장지수 범위는
`artifacts/df007/expansion-proposal.json`에 전부 열거했다. 성과에 따른 종목 선택은 없다.
현재 코드/시장 표기가 있는 미확보 후보만 산정한 **249개 코드·396개 합친 구간**이다.
42개 누락 코드 등을 추후 복원하더라도 이 제안에 자동 추가되지 않는다.

| 항목 | 산정값 |
|---|---:|
| 원/수정 종목 가격 예상 페이지 | 956 |
| 달력일 수를 모두 행으로 보는 보수적 종목 페이지 | 1,700 |
| 추가 지수 보수적 페이지 | 2 |
| 제안 PAPER 인증 최대 | 2 |
| 실패·요청별 재시도 1회 포함 KIS 최대 | **3,406** |

KIS 경로는 `inquire-daily-itemchartprice`(FHKST03010100),
`inquire-daily-indexchartprice`(FHKUP03500100)다. 주가 범위는 접수일 90일 전부터
21일 후의 보수적 검색 외피를 합쳤다. 필요한 연구 입력은 최소 21관측 세션 준비,
동결 5일 달력 만기와 이후 2관측 세션이다. 달력 외피가 적격 입력을 보장하지 않는다.
가장 이른 보수적 외피 때문에 지수 0001/1001의 2022-07-19~08-31 두 구간도 산정했다.
기존 2022-09 이후 지수로 충분한 사건은 이 추가 외피를 줄일 수 있지만,
자료를 확인하기 전 수집 효율을 좋게 보이도록 페이지를 과소 계산하지 않았다.

API가 실제로 해당 과거·폐지 종목 자료를 제공하는지는 아직 확인하지 않았다.
별도 승인 후 소규모 제공 범위 확인이 먼저다. 원문 검증 탈락과 데이터 공백을
합성 가격으로 메우지 않는다. 후속 정정 검색의 추가 기간은 별도 범위 정의가 필요하다.

기존 가격 캐시의 사건 적격 재사용률은 **2/620 = 0.323%**다. 다른 원시 DataStore
캐시도 조사했지만 DF005 외 실제 시세 시작일은 2025-10-17 이후라 이 사건 구간과
겹치지 않았다. 원본 49종목·지수 캐시는 그대로 남아 있다. 사건별 원/수정 계수,
거래정지와 권리/기업행위 계보가 없는 경우 적격으로 만들지 않는다.

3.10초 대기만 계산해도 KIS 최악 예산 약 176분, 원문 최악 예산 약 77분이다.
응답·재시도·오류 처리 시간은 별도다. 이는 기대 수익이 아니라 조사 비용 추정이다.
먼저 원문을 확인해야 실제 필요 가격 구간과 비용을 줄이거나 중단할 수 있다.

DF005의 900회나 DF006의 600회에서 남은 한도는 재사용하지 않는다. 이 파일은
승인 요청을 실행한 기록이 아니며 `execution_authorized=false`다. 승인 전 인증 호출은 없다.

## 수집 간격과 D2

DF006의 최소 3.035479초·70미준수는 보존했다. 별도 오프라인 보조 guard는 고해상도
3.10초 대기와 조기 깨어남 재검사를 하고, 관측 간격이 3.05초 미만이거나 이전 응답을
확인하지 못하면 추가 요청을 차단한다. 동결 수집기에 이를 몰래 연결하지 않았다.
새 승인 수집에서는 어댑터 경계에 연결해 UTC/고해상도 시각을 영속 기록하고 미준수 시
즉시 중단해야 한다. 실제 네트워크 준수는 **NOT_EXECUTED**다.

D2는 별도 가설·원문 공급 조사까지만 했다. 매매 규칙이나 가격 수집/성과 실험의
최종 비용은 독립 프로토콜 후 산정한다. B ORB 연구도 자동 시작하지 않았다.
